# UI Art Prompts — Small Icons

Shared rules for all icon assets:

- Icons render at 24–96 px in the HUD; the generated art must survive that shrink. **One bold silhouette, one dominant color, minimal interior detail.**
- Each icon is a single centered object isolated on a flat near-black background (`#101014`) with generous empty margin, generated square (1:1) and keyed/cropped in-engine.
- **No text or numbers in the artwork** — counts and values are rendered in HTML on top or beside the icon.
- Palette anchors: aether/mana = arcane blue-cyan; attack = steel and ember; health = ruby red; gold = warm yellow gold; Aethershard (premium) = warm golden-white songlight, visually distinct from plain gold; pack = neutral parchment plus warm shard glow.
- Style stays painterly fantasy per the art bible — no flat vector/sticker style, no photorealism.
